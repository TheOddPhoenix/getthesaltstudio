# Product photos

Place approved photos here using lowercase, hyphenated filenames (for example mothman-tee.webp).
Set the matching product's optional `image` field to `/images/mothman-tee.webp` in the catalog or Product Studio.
Allowed formats: .webp, .png, .jpg, .jpeg. Use descriptive alt context and appropriately licensed artwork.
Without an image field, the clearly labeled vector product placeholder remains visible.

Hero photos and approved logo/collection artwork can be supplied separately; current hero and logo are placeholders.
